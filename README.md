# AWSM Draper — Strategy Tool

This repository contains the AWSM Strategy Tool (codename: Draper) — an AI-powered advertising and brand strategy assistant built on AWSM's proprietary strategy framework.

## Repository Contents

- `draper-system-prompt.md` — The system prompt. Paste this into your Claude project instructions to activate the tool.
- `draper-tester-guide.md` — Setup and usage guide for testers.
- `draper-weekly-debrief.md` — Weekly feedback template. Complete and return to the AWSM team by end of Friday each week.

## Getting Updates

When a new version of the system prompt is released, download the updated `draper-system-prompt.md` and replace your project instructions with the new content. Check the Releases section for the latest version.

## Access

This is a private repository. If you have been given access, you are part of the AWSM Draper beta testing programme.
